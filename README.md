# Sistema de Servicios Escolares

## Descripción

Proyecto simulado desarrollado para la materia **Administración de Proyectos Informáticos** de la **Licenciatura en Informática**.

El proyecto representa un sistema de servicios escolares orientado a la gestión y consulta de información de estudiantes. Para su organización se utiliza gestión visual mediante Trello, control de versiones mediante Git y GitHub, y documentación técnica mediante el enfoque **Docs as Code** utilizando LaTeX y Overleaf.

## Tecnologías y herramientas

* Trello
* Git
* GitHub
* SQL
* LaTeX
* Overleaf

## Objetivo

Aplicar herramientas y prácticas de administración de proyectos informáticos para organizar, versionar y documentar un sistema de servicios escolares.
